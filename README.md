# Portfolio Website

Welcome to my portfolio website repository! This project is built using React JS for developing an interactive and dynamic user interface. It incorporates Tailwind CSS for styling and GSAP for advanced animations, offering a fast and responsive user experience. The website showcases my professional projects, skills, and experiences. This project is still under active development, and new features and improvements are being added regularly.

## Demo

Experience the website first-hand:
- **Live Demo**: [Visit here](https://ibrahimelmailoudi.github.io/Portfolio_website/) to see the portfolio in action.

## Features

- **Responsive Design**: Crafted with Tailwind CSS, the website is fully responsive and optimized for devices of all sizes.
- **Advanced Animations**: Leveraging GSAP for smooth, high-performance animations.
- **Modern UI/UX**: A clean and modern user interface with engaging transitions and animations.
- **Portfolio Projects**: Detailed sections for each project with images, descriptions, technologies used, and links to live sites or code repositories.
- **Contact Form**: Integrated contact form for easy communication.

## Technologies

- **React JS**: For building the component-based user interface.
- **Tailwind CSS**: For utility-first styling that can be customized to fit the design needs of the project.
- **GSAP**: For rich, interactive animations.
- **Vite**: As a build tool that offers a faster and more efficient development setup than traditional tools.
